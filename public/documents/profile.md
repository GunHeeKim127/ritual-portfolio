# 김건희 자기소개서

저는 상대의 이야기를 끝까지 듣고 핵심을 정리하며, 함께 해결할 방법을 찾는 김건희입니다.

2018년, 대학교 졸업과제로 스마트 미러를 만들던 중 함께하던 인원이 개인 사정으로 빠졌습니다. 남은 인원이 역할과 일정을 다시 정해야 했고, 저는 그 빈자리를 맡아 프로젝트를 이어갔습니다. 사람마다 급한 사정이 있을 수 있다는 점을 이해하면서도, 지금 남은 일을 어떻게 마무리할지 판단해야 했습니다.

제가 바꾼 것은 일의 순서였습니다. 한 번에 모든 문제를 해결하려 하기보다 할 수 있는 일을 나누고, 꼭 필요한 기능부터 완성하는 방향으로 우선순위를 정했습니다. 이 경험은 2026년 9월 10일 리추얼에서 다시 돌아본 장면이기도 합니다. 소설 1장의 “첫 번째 로그”가 보여 주는 출발점처럼, 제게 자기조절력은 계획이 달라졌을 때 확인한 사실과 다음 행동을 구분하고 실행 순서를 다시 세우는 태도입니다.

2023년 2월부터 2025년 6월까지 스타 법무법인 전략기획본부에서 주임·팀원으로 웹개발을 담당했습니다. 단독 프론트엔드 개발을 맡은 프로젝트가 많아 기획·디자인·백엔드·협력업체와 데이터 형식과 사용자 흐름을 맞추며 운영 가능한 결과를 만들었습니다.

사내 통계와 콘텐츠 등록을 자동화해 각각 약 3시간을 줄였고, PHP 화면의 React 전환과 신규 플랫폼 연동을 수행했습니다. 이후에는 Resource Name System의 흐름도와 데이터 구조를 설계하는 백엔드 업무에도 참여했습니다. 이 경험을 통해 대인관계력은 서로 다른 역할의 조건을 실제 결과로 연결하는 능력임을 배웠습니다.

전자정보통신공학 전공에서 이미 통신·네트워크를 배웠고, 2026년에는 이를 심화 실습했습니다. 소설 8장 “끊어진 패킷”의 핵심도 새로운 분야를 처음 만난 이야기가 아니라, 배운 지식이 실제 연결을 보장하지 않을 때 확인할 조건을 다시 찾는 과정입니다.

8월 27일에는 진행하던 실습이 되지 않아 전부 초기화하고 처음부터 다시 수행했습니다. 잘되지 않을 때 같은 방법만 반복하기보다 다시 시작할 방법을 선택했습니다. 8월 31일에는 컨디션이 좋지 않아 내용이 잘 들어오지 않았지만, 모든 내용을 타이핑하며 그날 이해할 수 있는 만큼 따라갔습니다. 매번 완벽하게 해결했다고 말할 수는 없습니다. 다만 끝나지 않은 일과 아무것도 하지 않은 일을 같게 두지 않고, 다음에 확인할 행동을 남겼습니다. 이것이 제 자기동기력의 근거입니다.

9월 28일에는 과제의 규모가 커지자 조원들에게 함께 확인해 달라고 부탁했습니다. 책임감을 모든 문제를 혼자 떠안는 일로만 여기지 않기 위해서였습니다. 먼저 찾아본 내용을 공유하고, 막힌 부분은 도움을 요청하며, 제가 아는 것은 설명하는 쪽으로 일하는 방식을 넓혀 왔습니다.

8월 13일에는 기밀성과 무결성, 암호화 개념을 설명했고 동료로부터 이해에 도움이 되었다는 말을 들었습니다. 10월 1일에는 막힌 부분을 돌파할 실마리를 주었다는 감사를 받았습니다. 상대의 질문을 듣고 이해한 내용을 나누는 행동이 제 대인관계력을 보여 줍니다.

소설 12장 “마지막이 아닌 배포”처럼 지금의 포트폴리오도 완성됐다고 선언하는 자리가 아니라, 확인된 현재와 아직 모르는 부분을 나누어 기록하는 자리입니다. 기록은 잘한 날만 모으는 장식이 아니라 다음 행동을 고르는 기준이 되었습니다. 앞으로도 기술을 꾸준히 익히면서 팀원이 편하게 질문할 수 있고, 어려운 상황에서 함께 해결의 실마리를 찾는 동료로 성장하겠습니다.

## 세 능력이 드러나는 장면

- 자기조절력: 2018년 스마트 미러 졸업과제에서 팀 구성 변화 뒤 우선순위와 실행 순서를 다시 정함.
- 대인관계력: 2023~2025년 기획·디자인·백엔드·협력업체와 데이터 형식과 사용자 흐름을 조율하고, 2026년에는 동료와 해결 과정을 나눔.
- 자기동기력: 2026-08-27 실습을 초기화해 다시 수행하고, 08-31 가능한 학습 행동을 이어감.

## 소설 원문과 사실 대조

사용한 장은 1장, 8장, 12장입니다. 소설의 서사 구조와 중심 질문만 가져왔으며, 9번 확정 서사나 리추얼로 확인되지 않는 계절·공간의 감각 묘사·대화·기술 세부는 사실 문장에 넣지 않았습니다. 회사 경력은 2026-10-14 사용자가 직접 제공한 내용을 기준으로 연결했습니다.
