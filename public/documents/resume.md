# 김건희 이력서

연락: kimgunhee127@gmail.com · GitHub: https://github.com/GunHeeKim127

## 소개

2년 5개월 동안 웹 서비스를 개발하고, 배운 것을 기록과 협업으로 연결해 온 개발자입니다. 전자정보통신공학 전공에서 통신·네트워크를 배웠으며, TypeScript·Next.js·React 기반 프론트엔드 개발과 백엔드 데이터 구조 설계 경험이 있습니다.

## 경력

- 스타 법무법인 · 전략기획본부 · 주임/팀원 · 웹개발
- 2023.02~2025.06 · 2년 5개월
- 사내 통계 대시보드, 홈페이지 리뉴얼, 신규 플랫폼, 콘텐츠 관리 사이트 개발
- Resource Name System 연구와 백엔드 데이터 구조 설계 참여

## 기술

- 개발: TypeScript, Next.js, React, Recoil, PostgreSQL, CSS, MUI, AWS, Docker, QGIS
- 협업: Git, Notion, Figma, Slack
- 기반: 전자정보통신공학, 통신·네트워크, 정보보안 개념

## 주요 성과

- 사내 통계 집계 자동화로 보고 작업 시간 약 3시간 단축
- 콘텐츠 등록 자동화로 콘텐츠 제작·등록 시간 약 3시간 단축
- PHP 기반 레거시 화면을 React 환경으로 전환해 유지보수 편의 개선
- RNS 흐름도·순서도와 데이터 구조를 설계해 고객 데이터 접근 과정 단순화

## 추가 프로젝트

- 2018년 스마트 미러 졸업과제: 팀 구성 변화 뒤 역할과 일정을 다시 정하고 필수 기능부터 완성해 프로젝트를 마무리했습니다.
- 2026년 네트워크·보안 심화 실습: 막힌 실습을 초기화해 다시 수행하고, 동료의 질문을 듣고 개념과 해결 실마리를 설명했습니다.
- 2026년 국내 알약 식별 연구 초안: OpenCV 전처리와 비전 LLM 비교 실험을 설계하고 국내 기준자료와 평가 절차를 정리했습니다.

## 강점

- 자기조절력: 상황이 바뀌면 우선순위와 실행 순서를 다시 세웁니다.
- 대인관계력: 서로 다른 역할의 요구를 듣고 데이터와 사용자 흐름으로 정리합니다.
- 자기동기력: 실패한 실습도 원인을 돌아보고 다시 시작합니다.
