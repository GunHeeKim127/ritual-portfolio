## 초록

본 연구는 별도 분류기 학습 없이 비전 언어모델이 알약 이미지를 식별하는 성능을 평가하고, 동일한 정보를 제공받은 인간 판독과 비교하여 향후 복약기의 식별 보조 기능에 적용할 기술적 가능성을 검토한다. 예비실험에서는 미국 공개 자료의 등록 제품 5종과 미등록 제품 2종에 해당하는 시험사진 28장을 사용하였다. 원본, OpenCV 보조 영상, 수치 특징 및 OpenGL 비교판으로 구성한 네 입력 조건에서 등록 제품 20건 중 15건을 식별하고 미등록 8건을 거절하였다. 그러나 조건별 사진이 다르고 같은 대화에서 평가했으므로 방법 간 우열이나 국내 약 성능을 입증하는 결과로 해석하지 않았다. 국내 본시험 준비를 위해 식약처 API에서 1,000행을 수집하여 중복을 제외한 999개 품목을 확보하고 등록 후보 10종 및 미등록 후보 6종의 기준사진을 내려받았다. 일부 기준사진과 색상 메타데이터의 불일치 가능성을 발견하여 후보 확정을 보류하였다. 본시험은 독립 시험사진, 동일 입력 조건, 명시적 UNKNOWN, 인간 집단별 평가 및 기술 실패를 포함하는 지표를 사용하도록 설계하였다. 현재 결과는 연구 파이프라인의 실행 가능성과 데이터·전처리 검증의 필요성을 보여주며 인간 대비 우월성이나 실제 복약기 적용 가능성이 확정되었음을 뜻하지 않는다.

주요어: 알약 식별, 비전 언어모델, 인간 판독, 오픈셋, OpenCV, 복약기

## 1. 서론

복약기에 이미지 식별 기능을 도입하려면 사진에서 정확한 제품을 구별하는 능력과 잘못된 후보를 선택하지 않는 능력을 함께 검증해야 한다. 같은 색과 모양을 가진 제품은 각인이나 다른 면의 관찰이 필요할 수 있다. 선명한 사진이어도 식별에 필요한 정보가 모두 노출되는 것은 아니며, 반대로 충분한 증거가 있는데도 모델이 식별하지 못한 경우를 단순히 안전한 거절이라고 평가해서는 안 된다.

본 연구의 목적은 국내 알약의 제품 식별 성능을 측정하고 동일한 과제를 수행하는 일반인 및 전문가와 비교하는 것이다. 앱 구현, 복용 알림, 실제 복약 행동의 확인은 현재 연구 범위에서 제외한다. 이미지 판독 결과와 사용자가 실제로 약을 복용했다는 사실은 별개다. 복약기 적용은 기술적 결과에 근거한 후속 활용 가능성으로 논의한다.

연구의 예정 기여는 ① 국내 공식 제품 ID와 독립 촬영 자료를 연결한 평가 절차, ② 인간과 비전 LLM의 동일 정보 비교, ③ 전처리의 이득과 실패를 함께 측정하는 분석이다. 이 세 항목 중 현재 완료된 부분과 미완료된 부분을 결과에서 구분한다. 별도 분류기 학습은 하지 않지만 LLM 자체는 사전학습 모델이므로 ‘머신러닝을 사용하지 않는다’고 표현하지 않는다.

## 4. 자료 수집과 정답 구축

### 4.1 실제 확보한 국내 기준자료

2026-10-07 식약처 API 연결 및 이미지 제공을 확인하였다. API가 반환한 전체 건수는 당시 25,437건이었다. 본 단계에서는 첫 10페이지에서 페이지당 100행을 수집했다. 총 1,000행 중 품목코드 200906540이 중복되어 고유 품목 수는 999개였다. 따라서 이 자료는 전수 자료나 확률표본이 아니다. 페이지별 응답과 중복 기록을 보존했다.

이미지·각인·장축·모양·색 정보가 있는 991개 품목을 개발용 후보군으로 삼았다. 같은 등록 모양·색, 장축 차이 0.5mm 이하, 다른 각인을 기준으로 중복되지 않는 3쌍을 선택하고 외형 다양성을 추가해 등록 후보 10종을 정했다. 유사 외형의 다른 제품 6종은 미등록 후보로 분리했다. 선택 규칙과 seed 20261007을 저장했다. 이는 관찰된 오분류를 보고 고른 혼동쌍이 아니라 메타데이터 기준의 잠정 혼동쌍이다.

16개 기준사진 모두 다운로드·디코딩에 성공했고 파일 해시는 서로 달랐다. 등록 후보 비교판을 시각 검토한 결과 K04와 K08에서 등록 색상과 사진의 색상 차이가 의심되어 추가 확인 대상으로 지정했다. 데이터 오류로 단정하거나 원자료를 임의 수정하지 않았다. 현재 판매·허가 상태와 독립 시험사진의 품목 대응을 검증하기 전에는 최종 카탈로그로 확정하지 않는다.

### 4.2 독립 시험자료

AI Hub의 경구약제 이미지 자료는 기관이 약을 구입하여 촬영한 사진과 제품·촬영·객체 위치 라벨을 제공한다고 안내한다[3]. 품목기준코드 필드가 있어 식약처 자료와의 교차 매핑을 검토할 수 있다. 실제 다운로드 승인이 필요한 자료이며 현재는 소개와 라벨 구조를 확인한 상태다. 사이트의 과거 제공 방식 설명과 현재 변경 이력을 구분하고, 로그인 후 해당 데이터의 현재 이용 조건을 확인한다. 인증이 없는 우회 경로로 자료를 수집하지 않는다.

다운로드 후 item_seq를 기준으로 교차 매핑하되, 코드 일치만으로 충분하다고 보지 않는다. 이름·각인·형태·자료 연도와 사진을 대조한다. 같은 이미지 또는 파생 이미지, 같은 실물/촬영 세션은 그룹으로 묶어 기준·개발·시험 사이에 누수되지 않게 한다. 공개 데이터의 사전학습 포함 여부는 확인할 수 없다는 한계도 남는다.

본시험 목표는 정상 단일약 100장, 어려운 단일약 40장, 미등록 단일약 60장 및 복수약 부가시험 30장이다. 기준·개발 자료는 별도로 둔다. 목표 수량은 확보 완료를 뜻하지 않는다. 조건과 그룹별 독립성이 부족하면 수량을 줄이고 적용 범위를 축소한다. 회전·가림 합성 사진은 별도 합성 실험으로만 보고한다.

### 4.3 정답 단위

주정답은 `KR:MFDS:<품목기준코드>`에 대응하는 정확한 제품 ID다. 제품명·성분·함량만의 일치는 별도 부분 정보 지표로 보고한다. 등록 ID K01~K10은 운영 카탈로그에서 제품명에 매핑하고 UNKNOWN은 최종 이름을 비운다. 실제 후보 밖 품목 ID는 운영자 정답 파일에 보존하되 판독자에게 공개하지 않는다. 두 객체를 같은 실물의 앞뒤라고 임의로 연결하지 않는다.

## 5. 시스템 및 평가 조건

OpenCV는 객체 후보 검출·crop·대비 보조·수치 특징을 만든다. 마스크가 있다는 사실만으로 알약 검출에 성공했다고 판정하지 않는다. 검출 정답과 비교하고 원본도 항상 보존한다. 잘못 잘린 crop을 모델에 제공한 경우도 실패 분석에 포함한다.

OpenGL은 기존 영상의 비교판 렌더링을 담당한다. 보이지 않는 표면이나 각인을 생성하지 않는다. CPU와 GPU의 출력 픽셀 일치는 구현 검증이며 제품 식별 능력 향상의 증거가 아니다.

본시험은 원본 A0, 원본+crop/대비 A1, A1+수치 특징 A2, 비교판+특징 A3를 동일 시험사진에 적용하도록 설계한다. 제공 해상도·이미지 수·레이아웃·토큰·처리시간 차이를 공개한다. 시간이 제한되면 A0/A2를 주비교로 정하고 나머지를 부가 실험으로 축소한다. 시험 후 유리한 조건만 선택해 보고하지 않는다.

호출별 독립 문맥, 정확한 모델 버전, 지원되는 설정, 원응답, 프롬프트·이미지 해시, 실행 시각을 기록한다. 현재 식약처 API는 연결됐으나 독립 비전 LLM API 평가 연결은 아직 완료되지 않았다. 동일 대화의 관찰을 통제된 독립 모델 평가라고 부르지 않는다.

OPEN은 등록·미등록 이미지를 함께 시험하며 UNKNOWN을 허용한다. OPEN의 등록약 부분집합을 별도로 실행한 CLOSED라고 표현하지 않는다. 외부 검색 허용 실험은 별도 조건으로 분리한다.

## 6. 인간 비교와 분석 방법

일반인과 약사 등 전문가를 별도 집단으로 모집한다. 미모집 집단은 결과를 비워 두며 연구자의 관찰로 대체하지 않는다. 참가자와 LLM 모두 동일 기준 카탈로그·이미지·검색 권한을 제공받는다. 같은 참가자의 반복 이미지 노출을 줄이고 입력 조건의 순서를 교차 배정한다. 정답 구축자와 판독자의 역할을 분리하고 본시험 전에 피드백을 제공하지 않는다.

기관의 연구윤리 검토 요건과 동의 절차를 모집 전에 확인한다. 참가자에게 실제 복용이나 처방 변경을 요구하지 않는다. 참가자 수·전문성·관련 경험과 개인별 성능을 보고한다. 인간 결과를 얻기 전에는 인간 대비 우수성을 결론내리지 않는다.

### 6.1 주요 지표

등록약 정확도는 `올바른 등록 제품 ID 수 / 모든 등록약 시험 기회`다. UNKNOWN과 기술 오류도 분모에 포함한다. 미등록 오수락률은 `미등록 사진에 등록 ID를 반환한 수 / 모든 미등록 시험 기회`다. coverage는 `등록 ID 반환 수 / 모든 시험 기회`, selective accuracy는 `올바른 ID 수 / ID 반환 수`다. 거절률과 기술 오류율을 따로 표시한다.

클래스 c에 대해 Precision=TP/(TP+FP), Recall=TP/(TP+FN), F1=2TP/(2TP+FP+FN)이며 클래스별 F1의 평균을 macro F1로 제시한다. 미정의 값의 처리 규칙을 사전 고정하고 지원 표본 수를 함께 제공한다. 예를 들어 기존 등록약 20건에서 15건 식별·5건 거절은 75%이며 거절을 정답에 더하지 않는다. 이 값은 네 입력 조건의 기술적 합계로 단일 모델 구성 성능이 아니다.

복수약은 가시 객체의 검출/매칭 이후 식별과 사진 내 모든 객체의 완전 일치를 구분한다. 사진 총 개수를 모르면 임의 정답을 부여하지 않는다. 모델 응답 누락·파싱 오류·시간 초과도 별도 기록한다.

### 6.2 불확실성과 대응 비교

제품·이미지·참가자 반복 측정을 고려한다. 사람의 여러 답을 독립 이미지처럼 합산하지 않는다. 일차적으로 참가자별 지표와 동일 문항의 대응 차이를 보고하고, 충분한 표본이 확보되면 참가자·이미지 군집을 반영한 재표집 또는 혼합효과 분석을 사전 명시한다. 모델의 자기보고 confidence는 보정된 정답 확률로 간주하지 않는다.

독립 시행을 가정할 때 오류 0건의 단측 95% 상한은 `1−0.05^(1/n)`이다. 작은 자료의 0건 오류가 낮은 오류율을 입증하지 못함을 보여주는 계산이며, 의존적인 사진 수를 그대로 n에 넣어 안전성을 주장하지 않는다[5].

## 7. 현재 완료한 결과

### 7.1 해외 예비실험

|입력 조건|등록 제품 식별|미등록 거절|전체 정답|
|---|---:|---:|---:|
|A0|4/5|2/2|6/7|
|A1|3/5|2/2|5/7|
|A2|3/5|2/2|5/7|
|A3|5/5|2/2|7/7|

조건별로 서로 다른 사진을 평가했고 동일 대화의 문맥이 누적됐으며 평가일도 달랐다. 이 표는 기록된 관찰값으로 보존하고 인과적 우열을 주장하지 않는다. 알려진 약의 실패 5건은 모두 UNKNOWN이었다. 일부 전처리는 실제 알약 대신 배경·그림자를 추출했다. A3의 5/5를 일반 정확도 100%라고 표현하지 않는다. 원시 기록과 상세 구현은 [기존 파일럿 원고](OpenCV_OpenGL_비전LLM_알약식별_실제파일럿_논문.md)에 있다.

### 7.2 복수약 탐색 사례

공개 실사진 두 장에 같은 윤곽선 처리를 적용했을 때 분리 배치의 네 객체는 각각 구분됐고 밀집 사진은 여러 약이 연결돼 분리에 실패했다. 분리된 사진의 두 객체는 사후 공식 라벨 검색으로 성분·함량 후보를 부여했으나 이는 제품 ID의 블라인드 정답률이 아니다. 나머지 두 객체는 현재 보이는 면의 정보가 부족했다. 상세 근거는 [복수약 보고서](multipill_analysis/복수알약_실제사진_분석보고서.md)에 보존했다.

### 7.3 국내 자료 및 평가 도구 검증

실제 완료 범위는 기준정보 1,000행/999품목, 잠정 후보 16종의 이미지 다운로드 및 해시 검사, 등록 후보 비교판 검토, 공통 판독 지시문과 채점 도구 작성이다. 채점 도구는 응답 누락·잘못된 ID·잘못된 선택·알려진 약 거절·중복 응답을 구별하는 합성 단위 테스트를 통과했다. 해당 합성 테스트는 약 식별 성능 결과가 아니다.

### 7.4 국내 기준사진 전처리 개발 검증

등록 기준사진 10장에 실제 전처리를 적용하고 수정 전후 결과를 보존했다. 초기 방식은 고정 관심영역과 배경 추정 위치 때문에 미검출·분할·경계 잘림이 발생했다. 가장자리 배경 추정과 관심영역 제한 제거 등으로 수정한 뒤 10장 모두 앞뒤 면에 대응하는 두 후보 영역을 반환했고 비교판을 직접 검토했다. 이는 같은 개발자료에 맞춰 개선한 결과로서 제품 식별 정확도나 독립 시험 성능이 아니다. 정밀 마스크 정답에 대한 IoU도 아직 계산하지 않았다. [전처리 개발 검증](korean_pill_data/전처리_개발검증.md)에 실제 수치·그림·한계를 수록했다.

## 8. 논의

예비 결과는 모델의 최종 후보 선택만큼 입력 영역과 기준정보의 정확성이 중요함을 보여준다. 배경을 추출한 수치 특징이나 잘못된 색상 라벨은 추가 정보가 오히려 판단을 방해할 수 있는 경로다. 따라서 정보량이 많다는 이유만으로 성능 개선을 가정하지 않는다.

사용 가능성은 특정 후보 수·촬영 조건·오류 수준에 한정해 논의해야 한다. 알려진 약의 정상 사진에서 과도하게 거절하거나 미등록 약에 등록 ID를 부여한다면 개선이 필요하다. 사람이 더 잘하는 조건과 모델이 더 잘하는 조건을 모두 보고하고, 통계적 차이와 실질적인 오류 감소를 구분한다.

현재 원고의 한계는 국내 독립 시험과 인간 비교 미실시, 소규모 해외 파일럿, 비독립 문맥, 카탈로그의 편의적 부분 수집, 잠정 후보의 외형 불일치, 공개 이미지 사전학습 노출 가능성이다. 자료 구축 시대와 현재 의약품 외형의 변화도 확인해야 한다. 실제 임상 사용이나 복용 사실 확인을 입증하지 않았다.

## 9. 결론

본 연구는 알약 식별의 실제 예비실험 기록을 정리하고 국내 제품 기준정보 및 인간–LLM 공통 평가 절차를 구축하였다. 확보 자료에서 전처리 실패와 기준정보 검토 필요성을 확인했다. 국내 제품 식별 정확도, 인간 대비 차이 및 복약기 적용 가능성의 최종 판단은 독립 시험자료와 실제 인간 판독 응답을 수집한 뒤 수행해야 한다. 현재 단계에서는 미실행 결과를 추정값으로 채우지 않는다.
