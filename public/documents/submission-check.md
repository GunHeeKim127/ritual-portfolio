# 제출 확인 방법과 AI 협업 기록

공개 HTTPS 사이트: https://ritual-portfolio.vercel.app/

이야기: 첫 화면 ‘나의 성장 과정 읽기’ 또는 소개의 ‘배움과 성장의 과정 읽기’. 숫자: ‘기록’ 영역과 ‘숫자와 출처 확인’. 대표작: ‘작업’ 영역의 논문·앱 카드. 문서: ‘문서’ 영역에서 DOCX 다운로드. 장치: 맨 아래 ‘갱신과 검토 과정 보기’의 ZIP 다운로드.

ZIP의 scripts에는 실행 소스와 테스트, README-refresh.md에는 세 단계 실행 방법, inputs에는 공개용 입력, last-result.json에는 마지막 결과가 있습니다. repeat-check.json에는 같은 입력을 두 번 실행한 검증 결과가 있습니다.

1. AI에게 맡긴 일: 기존 디자인 유지, 확정 서사와 리추얼 대조, 자기소개 편집, 숫자 집계, DOCX 생성, 결정론적 후보·승인 장치, 테스트, 공개 배포 설정.
2. 내가 직접 판단한 일: 기존 하이브리드 화면을 유지하고 버튼으로 상세 내용을 읽는 방향, 공개 사이트와 제출물의 최종 사용 여부.
3. AI 제안을 따르지 않은 일: 문서 전체를 별도 모달 중심으로 바꾸자는 방향은 철회하고 이전 화면으로 되돌렸습니다. 현재 화면이 더 좋다고 판단했기 때문입니다.

추가 과제 원문 반영: 13번 앱은 아직 없으므로 대표작 자리를 비워 두고 ‘13번 완료 후 채움’으로 표시했습니다. 방문자 통계·댓글·로그인 기능은 넣지 않았습니다. 본인 이름과 공개 연락 수단 하나만 남기고, 동료의 실명은 공개하지 않았습니다.

11번 소설 대조: 1장·8장·12장을 선택하고, 9번 확정 서사와 리추얼로 확인되지 않는 각색은 제외했습니다.

확인 한계: 13주 전체 출석·제출 원본은 확보되지 않았습니다. 해당 숫자는 추정하지 않았습니다.
