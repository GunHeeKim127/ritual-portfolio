# 제출 확인 방법과 AI 협업 기록

공개 HTTPS 사이트: 아직 배포하지 않았습니다. localhost나 GitHub 저장소 주소를 결과물 URL로 제출하지 마세요.

이야기: 첫 화면 ‘나의 이야기 읽기’ 또는 소개의 ‘고난에서 지금까지 읽기’. 숫자: ‘기록’ 영역과 ‘숫자와 출처 확인’. 대표작: ‘작업’ 영역의 논문·앱 카드. 문서: ‘문서’ 영역에서 읽기 또는 MD 다운로드. 장치: 맨 아래 ‘갱신과 검토 과정 보기’의 ZIP 다운로드.

ZIP의 scripts에는 실행 소스와 테스트, README-refresh.md에는 세 단계 실행 방법, inputs에는 공개용 입력, last-result.json에는 마지막 결과가 있습니다. repeat-check.json에는 반복 실행 검증 상태가 있습니다.

1. AI에게 맡긴 일: 기존 디자인을 유지한 상세 모달 구현, 확정 서사와 리추얼의 대조·자기소개 편집안, 숫자 집계, 결정론적 문단 후보·승인 장치, 테스트 및 파일 정리.
2. 내가 직접 판단한 일: 기존 화면이 좋다고 판단해 유지하고, 버튼으로 관련 이미지와 상세 내용을 읽는 방식을 요청했다. 확장 자기소개 본문의 최종 선택은 아직 확인해야 한다.
3. AI 제안을 따르지 않은 일: 이번 보완에서 명시적으로 거절한 AI 제안은 아직 확인되지 않았다. 기존 디자인 유지 요청은 본인이 정한 방향이다. 새 본문을 검토한 뒤 따르지 않은 제안이 있다면 그 이유를 직접 추가한다.

남은 확인: 11번 소설과의 대조, 새 소개 본문 및 첫/마지막 문장의 본인 최종 편집, 공개 연락 수단, 전체 13주 출석·제출 자료, 10번 논문, 앱 예정일, 동료의 실제 반응, 공개 배포 후 시크릿 창에서 모든 URL 확인.
