# 김건희 경력기술서

## 경력 요약

스타 법무법인 전략기획본부에서 주임·팀원으로 웹개발을 담당했습니다. 단독 프론트엔드 개발을 중심으로 기획·디자인·백엔드·협력업체와 함께 사내 운영 도구, 홈페이지, 신규 플랫폼과 콘텐츠 관리 시스템을 만들었으며, 2025년에는 백엔드 데이터 구조 설계에도 참여했습니다.

- 회사: 스타 법무법인
- 소속·직급·역할: 전략기획본부 · 주임/팀원 · 웹개발
- 근무기간: 2023.02~2025.06 · 2년 5개월
- 주요 기술: TypeScript, Next.js, React, Recoil, PostgreSQL, CSS, MUI, AWS, Docker, QGIS
- 협업 도구: Git, Notion, Figma, Slack
- 공개 범위: 회사 홈페이지처럼 공개된 결과만 링크할 수 있으며, 관리자 페이지·내부 운영 화면·소스코드·비공개 데이터는 회사 자산이므로 공개하지 않음

## 1 사내 통계 데이터 대시보드 및 업무 관리 사이트

기간: 2023.05~2024.07

구성: 프론트엔드 1명 · 백엔드 1명 · 기획 2명

주요 업무:
- 인증·권한에 따른 사용자 흐름을 개선하고 페이지 기획에 참여
- 데이터 집계 결과를 시각화하는 기능 개발
- REST API 통신을 위한 데이터 형식을 설계하고 백엔드 개발자와 협업
- UI와 UX를 직접 개선하고 운영 중인 화면을 유지보수

주요 성과:
- 데이터 집계를 자동화해 보고 작업 시간을 약 3시간 단축
- 운영 부서가 통계와 업무 현황을 확인하는 과정의 사용 편의 개선

## 2 홈페이지 리뉴얼 및 유지보수

기간: 2024.08~2025.02

구성: 프론트엔드 1명 · 디자인 1명

주요 업무:
- PHP 기반 레거시 화면을 React 환경으로 전환
- 검색 노출을 위한 SEO 관리와 UI·UX 개선 및 유지보수

주요 성과:
- 화면 구조를 정리해 유지보수와 운영 편의 개선
- PHP와 React 환경을 함께 사용할 수 있는 전환 구조 확보

## 3 신규 플랫폼 개발

기간: 2024.05

구성: 프론트엔드 1명 · 프로젝트 관리자 1명 · 협력업체 2명

주요 업무:
- 협력업체와 역할과 연동 범위를 조율하며 플랫폼 개발
- REST API 통신을 위한 데이터 형식을 설계하고 백엔드 영역과 협업
- SEO 관리와 UI·UX 개선 및 유지보수

주요 성과:
- 고객 접근성을 높이고 SEO 관리를 통해 광고 유입 경로 확대

## 4 콘텐츠 관리 사이트 개발

기간: 2024.07~2025.02

구성: 프론트엔드 1명 · 백엔드 1명

주요 업무:
- 콘텐츠 등록 게시판과 마크다운 게시판 개발
- 인증·권한에 따른 사용자 흐름 개선
- 카테고리·작성자·이미지·동영상 등 콘텐츠 등록 자동화 기능 개발
- REST API 데이터 형식을 설계해 백엔드 개발자와 협업하고 SEO 관리

주요 성과:
- 콘텐츠 제작과 등록 과정을 자동화해 작업 시간을 약 3시간 단축
- 콘텐츠 페이지 관리 절차 단순화

## 5 자사 Resource Name System 개발

기간: 2025.02~2025.06

구성: 백엔드 2명 · 백엔드 개발 참여

주요 업무:
- Resource Name System을 연구하고 업무 흐름도와 순서도 작성
- RNS 데이터 구조 설계와 구축에서 백엔드 핵심 역할 수행

주요 성과:
- 고객 데이터 위치를 시각화해 위치 확인과 접근 절차 간소화
- 관련 부서가 고객 데이터에 접근하는 시간 단축
